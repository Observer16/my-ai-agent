# 📄 Страницы приложения

Описание всех страниц Telegram Mini App.

## Основные страницы

### index.html - Главная страница (Dashboard)
- Главный экран приложения
- Статистика и информация о пользователе
- Быстрые действия и навигация
- Интеграция с модулем здоровья
- Интеграция с семейными данными

### pages/budget.html - Бюджет и расходы
- Анализ расходов по категориям
- Тренды и графики
- История покупок

### pages/family.html - Семья
- Управление членами семьи
- Приглашения в семью
- Общие данные и статистика

### pages/monthly-stats.html - Месячная статистика
- Детальная статистика по месяцам
- Анализ по категориям
- Сравнение периодов

### pages/products.html - Товары и цены
- Каталог товаров
- Поиск товаров
- Модуль сравнения цен

### pages/add-expense.html - Добавление расхода
- Форма добавления расхода
- Загрузка QR-кода чека
- Распределение товаров по категориям

### pages/settings.html - Настройки
- Язык и локализация
- Уведомления
- Профиль пользователя
- Дополнительные параметры

## Модульные страницы

### health-module/ - Модуль здоровья
- Отдельный модуль с собственной архитектурой
- Dashboard, Diary, Medications, Stats, Settings, Onboarding

## Паттерны разработки страниц

1. Каждая страница - отдельный HTML файл в `pages/`
2. Скрипты подключаются в правильном порядке (config.js первым)
3. Используется система переводов (i18n)
4. API вызовы через `window.API` клиент
5. Кэширование через `window.Cache`

Подробнее см. [Компоненты](./COMPONENTS.md) и [Стили](./STYLES.md)
