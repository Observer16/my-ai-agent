# 🔄 Миграции базы данных

Описание истории изменений схемы БД и процесса миграций.

## Процесс миграций

Миграции управляются из backend проекта `C:\Users\obser\PycharmProjects\FamilyBudgetAnalyzer`.

## Основные миграции

### v1.0 - Инициальная схема (Бюджет & Товары)

**Таблицы общего назначения:**
- `app_users` - учетные записи пользователей (привязаны к Telegram ID)
- `families` - семьи для совместного бюджета
- `family_members` - члены семьи (связь user-to-family)

**Таблицы товаров и магазинов:**
- `products` - товары (штрих-код, категория, бренд)
- `product_names` - многоязычные названия товаров (es, en, ru, uk)
- `stores` - магазины (адрес, телефон, RUC)
- `price_history` - история цен товаров

**Таблицы покупок:**
- `purchases` - документы закупок (счета)
- `purchase_items` - строки товаров в закупке
- `expense_categories` - категории расходов

### v2.0 - Модуль здоровья (Health Schema)

**Основные таблицы здоровья:**
- `health.user_profiles` - профили здоровья пользователя
- `health.health_goals` - цели и целевые показатели здоровья
- `health.entries` - записи в дневник здоровья (настроение, сон, вес)
- `health.symptoms` - симптомы в записях дневника
- `health.medications` - медикаменты и лекарства
- `health.medication_schedules` - расписание приема лекарств
- `health.medication_reminders` - напоминания о приеме лекарств
- `health.medication_logs` - логи приема лекарств

**Специализированные таблицы здоровья:**
- `health.dental_health` - стоматологические записи
- `health.immunizations` - прививки и иммунизация
- `health.medical_measurements` - медицинские измерения (давление, пульс и т.д.)
- `health.vision_health` - здоровье зрения
- `health.menstrual_cycle` - менструальный цикл
- `health.physical_activity` - физическая активность
- `health.water_intake` - водный баланс

**Уведомления и системные:**
- `health.notification_logs` - логи отправленных уведомлений
- `health.user_notification_settings` - настройки уведомлений пользователя

### v3.0 - Поддержка многопользовательской работы и расширения

**Новые таблицы:**
- `family_invites` - приглашения в семью с токеном и истечением
- `product_synonyms` - синонимы товаров для улучшения поиска
- `category_translations` - переводы названий категорий
- `tag_translations` - переводы тегов
- `activity_records` - логи активности пользователей
- `user_photo_reviews` - отзывы и фото товаров от пользователей
- `health_records` - общие медицинские записи

**Изменения существующих таблиц:**
- Добавление полей `family_id` в таблицы товаров, цен, покупок (изоляция данных)
- Добавление полей `created_by_user_id` для отслеживания автора
- Добавление полей `updated_at` и триггеров для отслеживания изменений
- Добавление индексов для оптимизации поиска по family_id и user_id

### v4.0 - Парсинг и интеграции

**Таблицы парсинга (parsing schema):**
- `parsing.offers` - предложения из парсинга (интеграция с внешними источниками)

## Ключевые архитектурные решения

### Схемы базы данных

**Public schema** - основные таблицы приложения
**Health schema** - модуль здоровья (отдельный namespace)
**Parsing schema** - данные из парсинга и интеграций

### Изоляция данных по семьям

- Поддержка двух режимов: **SOLO** (NULL family_id) и **FAMILY** (с family_id)
- Все таблицы с данными имеют поля `family_id` и `created_by_user_id`
- Фильтрация на уровне API через middleware
- Уникальные индексы учитывают user_id для SOLO режима

### Аудит и отслеживание

- Все таблицы имеют `created_at` и `updated_at` (с автоматическим триггером)
- Поле `created_by_user_id` для отслеживания автора записи
- Большинство таблиц имеют уникальные ограничения для предотвращения дубликатов

### Нормализация данных

- **product_names** - поддержка многоязычности (es, en, ru, uk) и локализации
- **product_synonyms** - синонимы для улучшения поиска и соответствия
- **category_translations** - переводы категорий расходов
- **normalized_name** - стандартизованное имя для поиска

### Интеграция с Telegram

- `X-Telegram-User-Id` header для аутентификации
- Все пользователи привязаны к Telegram ID
- Приглашения в семьи через токены (6-7 дней действия)
