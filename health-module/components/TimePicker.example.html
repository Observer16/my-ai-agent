⏰ TimePicker

iOS-Style Wheel Picker для выбора времени

📱 Базовый пример
00:00
✨ Попробуй: Прокрути колеса мышью или пальцем. Используй инерцию для быстрого выбора. На ПК поддерживается прокрутка колеса мыши.
💻 Как использовать
const picker = new TimePicker(containerEl, { initialHours: 14, initialMinutes: 30, hoursLabel: 'ч', minutesLabel: 'мин', format24h: true, minuteStep: 1, onTimeSelect: (hours, minutes) => { console.log(`Время: ${hours}:${minutes}`); } }); // Методы: picker.setTime(10, 45); // Установить время picker.getTime(); // { hours: 10, minutes: 45, formatted: "10:45" } picker.reset(); // Сброс на начальное время
✨ Особенности
✓ iOS-style wheel picker с инерцией
✓ Поддержка touch и mouse
✓ Прокрутка колеса мыши (wheel event)
✓ Гладкая привязка к ближайшему элементу
✓ Адаптивен для мобильных и ПК
✓ Поддержка 12/24 часового формата
✓ Настраиваемый шаг минут (1, 5, 15, 30 мин)
✓ Колбэк при выборе времени
✓ Поддержка темной/светлой темы
⚙️ Опции
initialHours (number): Начальные часы [0-23] (по умолчанию: 12)
initialMinutes (number): Начальные минуты [0-59] (по умолчанию: 0)
hoursLabel (string): Название часов (по умолчанию: 'ч')
minutesLabel (string): Название минут (по умолчанию: 'мин')
format24h (boolean): 24-часовой формат (по умолчанию: true)
minuteStep (number): Шаг минут [1, 5, 15, 30] (по умолчанию: 1)
onTimeSelect (function): Колбэк при выборе времени
