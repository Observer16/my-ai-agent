# 🔍 Модуль "Поиск товаров"

Модуль поиска товаров по названию и штрих-коду с модальным просмотром.

## 📋 Описание

Страница `pages/products.html` позволяет:
- Искать товары по названию
- Искать товары по штрих-коду (сканирование QR)
- Просматривать детали товара в модальном окне
- Сравнивать цены товара в разных магазинах
- Видеть историю цен

## ✅ Функциональность

### Поиск
- Поиск по названию (реал-тайм)
- Поиск по штрих-коду (вввод или сканирование)
- Кэширование результатов
- Предложения и автодополнение

### Модальное окно товара
- Название и фото товара
- Текущая цена в магазинах
- История цен (граф/таблица)
- Информация о категории
- Кнопка закрытия (крестик)
- Поддержка Telegram BackButton

### Сравнение цен
- Таблица цен по магазинам
- Самая дешевая цена выделена
- Последний день покупки
- Тренд цены (вверх/вниз/без изменений)

### История цен
- График изменения цены за последние 90 дней
- Процент изменения
- Количество наблюдений

## 🔧 API Endpoints

### GET /products
Поиск товаров

**Параметры:**
- `search` - текст поиска
- `limit` - количество результатов
- `family_id` (optional) - семейные данные

### GET /products/by-code/{barcode}
Поиск товара по штрих-коду

**Параметры:**
- `barcode` - штрих-код товара
- `family_id` (optional) - семейные данные

**Ответ:**
```json
{
  "id": "123",
  "name": "Молоко",
  "barcode": "784150303152",
  "category": "молочные продукты",
  "photo_url": "https://..."
}
```

### GET /prices/trends
Тренды цен товара

**Параметры:**
- `days` - количество дней (default: 90)
- `product_name` (optional) - фильтр товара
- `family_id` (optional) - семейные данные

### GET /prices/compare
Сравнение цен в магазинах

**Параметры:**
- `product_name` (optional) - фильтр товара
- `family_id` (optional) - семейные данные

**Правила:**
- Показываются только товары из разных магазинов (2+)
- Исключаются товары с кодом "MANUAL" (вручную введенные)
- Требуется наличие QR-кода чека

## 🎨 UI Компоненты

### Поисковая строка
- Input с иконкой лупы
- Иконка сканирования QR
- Очистка при нажатии X
- Реал-тайм поиск с debounce

### Результаты поиска
- Карточки товаров
- Иконка товара
- Название и цена
- Клик открывает модальное окно

### Модальное окно
- Заголовок с названием товара
- Кнопка закрытия (крестик)
- Содержимое (таблица/граф)
- Поддержка BackButton

## ⚡ Оптимизация

- Кэширование результатов на 6 часов
- Debounce поиска (300ms)
- Ленивая загрузка результатов
- Минимальное количество символов для поиска (2)
