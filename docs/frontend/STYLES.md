# 🎨 CSS стили и дизайн

Описание стилей и системы CSS приложения.

## Структура CSS

### Файлы стилей
- **css/main.css** - основные стили приложения
- **css/components.css** - стили компонентов
- **css/health-module.css** - стили модуля здоровья
- **css/responsive.css** - адаптивная верстка

## Система цветов

Приложение использует цветовую схему, оптимизированную для Telegram Mini App:
- Первичный цвет - синий (гармоничный с Telegram)
- Вторичный цвет - зеленый (действия, успех)
- Нейтральные - серый, белый
- Предупреждения - оранжевый, красный

## Классы и компоненты

### Основные классы
- `.card` - карточки элементов
- `.modal` - модальные окна
- `.button` - кнопки
- `.input` - поля ввода
- `.badge` - значки и метки

### Адаптивность

Стили используют:
- CSS Grid для раскладки
- Flexbox для выравнивания
- Media queries для мобильных устройств
- CSS переменные для тем

## Переменные CSS

Основные переменные хранятся в `:root`:
```css
--primary-color
--secondary-color
--text-color
--bg-color
--border-color
```
