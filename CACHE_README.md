## ⚡ Как работает

### Автоматическое кэширование

Все GET запросы **автоматически кэшируются** с умным TTL:

```javascript
// Просто вызываешь API как обычно
const products = await API.getProducts();  // ← Кэшируется на 30 минут
const stores = await API.getStores();      // ← Кэшируется на 1 час
const stats = await API.getStatistics();   // ← Кэшируется на 5 минут
```

### TTL для разных данных

| Endpoint | TTL | Причина |
|----------|-----|---------|
| `/stores` | 1 час | Магазины редко меняются |
| `/categories` | 1 час | Категории редко меняются |
| `/products` | 30 мин | Товары иногда обновляются |
| `/statistics` | 5 мин | Статистика меняется часто |
| `/statistics/monthly` | 10 мин | Месячная стат реже |
| `/prices/trends` | 1 час | Тренды - исторические данные |
| `/prices/compare` | 30 мин | Сравнение цен |
| `/purchases/recent` | 5 мин | Последние покупки |
| `/family/members` | 10 мин | Участники семьи |
| `/family/info` | 5 мин | Инфо о семье |

### Не кэшируется

- ❌ `/family/invites/pending` - приглашения (нужна актуальность)
- ❌ `/auth/me` - профиль (может измениться)
- ❌ Все POST/PUT/DELETE запросы

## 🔄 Автоматическая инвалидация

При изменении данных кэш **автоматически очищается**:

```javascript
// Создаём товар
await API.createProduct({name: 'Молоко'});
// ✅ Кэш /products автоматически очищен

// Добавляем расход
await API.createExpense(storeId, productId, 1, 5000);
// ✅ Кэш /statistics, /purchases, /prices автоматически очищен

// Создаём магазин
await API.createStore({name: 'Супермаркет'});
// ✅ Кэш /stores автоматически очищен
```

## 🛠️ Ручное управление кэшем

### Очистить весь кэш

```javascript
API.clearCache();  // Очистить всё
```

### Очистить по паттерну

```javascript
API.clearCache('products');    // Только товары
API.clearCache('statistics');  // Только статистику
API.clearCache('family');      // Только семью
```

### Получить статистику

```javascript
const stats = API.getCacheStats();
console.log(stats);
// {
//   total: 15,         // Всего записей
//   valid: 12,         // Валидных
//   expired: 3,        // Устаревших
//   size_kb: 45,       // Размер в KB
//   enabled: true      // Включено
// }
```

### Управление через Cache напрямую

```javascript
// Отключить кэширование
Cache.setEnabled(false);

// Включить обратно
Cache.setEnabled(true);

// Очистить устаревшие записи
Cache.cleanup();

// Получить статистику
const stats = Cache.getStats();
```

## 🐛 Отладка

### Если кэш не работает

```javascript
// Проверь доступность localStorage
Cache.isAvailable();  // должно быть true

// Проверь что кэш включён
Cache.enabled;  // должно быть true

// Проверь логи
// Должны быть сообщения "💾 В кэш" и "💾 Из кэша"
```

### Если localStorage переполнен

Кэш **автоматически очищает** старые записи при переполнении.

```javascript
// Ручная очистка
Cache.cleanup();  // Удалит устаревшие
Cache.clear();    // Удалит всё
```
