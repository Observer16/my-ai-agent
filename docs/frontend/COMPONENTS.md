# 🎨 Компоненты Frontend

Описание переиспользуемых компонентов приложения.

## Список компонентов

### Основные компоненты
- **ComponentLoader** - динамическая загрузка HTML компонентов
- **Modal** - модальные окна
- **Card** - карточки товаров и элементов

### Модуль здоровья (health-module/)
- **Dashboard** - главный экран модуля здоровья
- **Diary** - дневник записей
- **Medications** - управление лекарствами
- **Stats** - статистика здоровья
- **Settings** - настройки модуля

## Архитектура компонентов

Компоненты организованы модульной архитектурой:
- Каждый компонент содержит свою логику и стили
- Используется паттерн `StateManager` для управления состоянием
- DOM обновления через `DomManager`
- События через `EventManager`
