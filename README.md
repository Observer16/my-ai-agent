## 📖 О проекте

**Мой Агент** — это Telegram Mini App, которое объединяет инструменты для управления здоровьем, отслеживания финансов и анализа покупок в одном удобном интерфейсе.

### ✨ Основные возможности

- 💪 **Модуль здоровья** — ежедневная оценка самочувствия, трекинг симптомов и лекарств
- 🏃 **Физическая активность** — учет тренировок, шагов и калорий
- 💰 **Управление финансами** — учет расходов, анализ трендов цен
- 🩺 **AI консультант** — медицинские консультации 24/7
- 👥 **Семейный режим** — совместный учет расходов и статистики
- 📊 **Аналитика** — детальная статистика по всем модулям

## 🚀 Быстрый старт

### Требования

- Современный браузер с поддержкой ES6+
- Telegram аккаунт для использования Mini App
- Доступ к API (см. [Конфигурация](#конфигурация))

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Observer16/my-ai-agent.git
cd my-ai-agent
```

2. Откройте `index.html` в браузере или разверните на веб-сервере

3. Настройте API endpoint в `js/config.js`:
```javascript
const CONFIG = {
    API_URL: 'https://api.smartsaving.fun'
};
```

### Запуск в Telegram

1. Создайте бота через [@BotFather](https://t.me/botfather)
2. Настройте Mini App через `/newapp`
3. Укажите URL вашего развернутого приложения
4. Откройте Mini App в Telegram

## 💾 Система кэширования

Приложение использует умную систему кэширования для оптимизации производительности:

- ⚡ **Автоматическое кэширование** всех GET запросов
- 🔄 **Автоматическая инвалидация** при изменении данных
- ⏱️ **Умные TTL** для разных типов данных (от 5 минут до 1 часа)
- 📊 **Мониторинг статистики** кэша в реальном времени

Подробнее: [CACHE_README.md](CACHE_README.md)

## 🔐 API Endpoints

### Аутентификация
- `GET /auth/me` - Получить профиль пользователя
- `PUT /auth/me` - Обновить профиль

### Расходы
- `GET /purchases` - Список покупок
- `POST /purchases` - Добавить покупку
- `GET /statistics` - Общая статистика
- `GET /statistics/monthly` - Месячная статистика

### Товары и магазины
- `GET /products` - Список товаров
- `POST /products` - Создать товар
- `GET /stores` - Список магазинов
- `POST /stores` - Создать магазин

### Семья
- `GET /family/info` - Информация о семье
- `POST /family/create` - Создать семью
- `POST /family/invite` - Пригласить участника

### Здоровье
- `GET /health/records` - Записи здоровья
- `POST /health/records` - Добавить запись
- `GET /health/medications` - Список медикаментов

Полная документация API: [API Documentation](https://api.smartsaving.fun/docs)

## ⚙️ Конфигурация

### js/config.js

```javascript
const CONFIG = {
    API_URL: 'https://api.smartsaving.fun',
    APP_VERSION: '0.5',
    CACHE_ENABLED: true
};
```

### Настройка кэширования

В `js/cache.js` можно настроить TTL для разных endpoint'ов:

```javascript
this.ttls = {
    'stores': 3600,        // 1 час
    'products': 1800,      // 30 минут
    'statistics': 300,     // 5 минут
    // ...
};
```

## 🧪 Разработка

### Структура кода

Приложение использует модульную архитектуру:

1. **Core** - базовые менеджеры (состояние, события, DOM)
2. **Components** - переиспользуемые компоненты
3. **Managers** - менеджеры функциональности
4. **Utils** - утилиты и хелперы

### Добавление нового модуля

1. Создайте HTML компонент в `pages/`

4. Добавьте карточку модуля на главную страницу

Включите подробные логи в консоли:

