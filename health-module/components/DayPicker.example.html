⏰ DayPicker

iOS-Style Wheel Picker для выбора дня/месяца/года

📱 Базовый пример
18.01.2026
✨ Попробуй: Прокрути колесики пальцем или мышью. Используй инерцию для быстрого выбора. На ПК поддерживается прокрутка колеса мыши.
💻 Как использовать
const picker = new DayPicker(containerEl, { initialDate: '2026-01-18', onDateSelect: (dateString) => { console.log(`Дата: ${dateString}`); } }); // Методы: picker.setDate('2026-02-15'); // Установить дату picker.getDate(); // "2026-02-15" picker.destroy(); // Уничтожить
✨ Особенности
✓ iOS-style wheel picker с инерцией
✓ Три независимых колеса: День, Месяц, Год
✓ Momentum scrolling с плавной инерцией
✓ Поддержка touch и mouse
✓ Прокрутка колеса мыши (wheel event)
✓ Автокоррекция дней при смене месяца
✓ 60 FPS производительность
✓ Адаптивен для мобильных и ПК
✓ Без зависимостей
⚙️ Опции
initialDate (string): Начальная дата YYYY-MM-DD (по умолчанию: сегодня)
onDateSelect (function): Колбэк при выборе даты
minDate (string): Минимальная дата YYYY-MM-DD (опционально)
maxDate (string): Максимальная дата YYYY-MM-DD (опционально)
format (string): Формат даты (по умолчанию: DD.MM.YYYY)
📊 Сравнение с DatePicker
DayPicker (колесики):
• Компактный размер
• Быстрый выбор через инерцию
• Идеален для мобильных
• Плавный скролл

DatePicker (календарь):
• Знакомый интерфейс
• Навигация по месяцам
• Может просмотреть весь месяц
• Ограничение дат (minDate/maxDate)
