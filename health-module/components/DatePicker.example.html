📅 DatePicker

Всплывающий календарь для выбора даты

📱 Базовый пример
18.01.2026
✨ Возможности: Выбор даты через всплывающий календарь. Навигация по месяцам и годам. Быстрый выбор через селекты. Можно установить ограничения (minDate, maxDate).
💻 Как использовать
const picker = new DatePicker(containerEl, { initialDate: '2026-01-18', minDate: '2020-01-01', maxDate: '2030-12-31', onDateSelect: (dateString) => { console.log(`Дата: ${dateString}`); } }); // Методы: picker.setDate('2026-02-15'); // Установить дату picker.getDate(); // Получить дату picker.destroy(); // Уничтожить
✨ Особенности
✓ Классический календарь с месяцами
✓ Навигация кнопками "пред/след месяц"
✓ Селекты для месяца и года
✓ Выделение сегодняшней даты
✓ Выделение выбранной даты
✓ Ограничение дат (minDate, maxDate)
✓ Кнопки Отмена и Выбрать
✓ Адаптивен для мобильных
✓ Без зависимостей
⚙️ Опции
initialDate (string): Начальная дата YYYY-MM-DD (по умолчанию: сегодня)
minDate (string): Минимальная дата YYYY-MM-DD (по умолчанию: null)
maxDate (string): Максимальная дата YYYY-MM-DD (по умолчанию: null)
onDateSelect (function): Колбэк при выборе даты
onCancel (function): Колбэк при отмене
