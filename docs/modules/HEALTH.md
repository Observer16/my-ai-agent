# 💊 Модуль "Здоровье"

Отдельный модуль для отслеживания здоровья: лекарства, симптомы, логи.

## 📋 Описание

Модуль здоровья - это отдельная архитектура в папке `health-module/` с собственной системой управления состоянием и UI компонентами.

**Путь:** `health-module/`

## ✅ Функциональность

### Профиль здоровья
- Личные данные (рост, вес, группа крови, дата рождения)
- История изменения веса
- Медицинские заметки

### Управление лекарствами
- Список текущих лекарств
- Дозировка и частота приема
- Напоминания об приеме
- История приема

### Дневник симптомов
- Ежедневная запись симптомов
- Оценка самочувствия (1-10)
- Заметки о настроении
- История наблюдений

### Логи здоровья
- История приема лекарств
- Отслеживание симптомов
- Медицинские вмешательства
- Экспорт данных

### Напоминания
- Напоминания об приеме лекарств
- Напоминания о записи к врачу
- Отправка через Telegram

## 🏗️ Архитектура

### Структура модуля
```
health-module/
├── js/
│   ├── health-module.js        # Main facade (HealthModule)
│   ├── main.js                 # UI initialization (HealthUI)
│   ├── core/
│   │   ├── state-manager.js    # управление состоянием
│   │   ├── dom-manager.js      # операции с DOM
│   │   └── event-manager.js    # обработчики событий
│   ├── components/
│   │   ├── dashboard.js        # главный экран
│   │   ├── diary.js            # дневник
│   │   ├── medications.js      # лекарства
│   │   ├── stats.js            # статистика
│   │   ├── settings.js         # настройки
│   │   └── onboarding.js       # приветствие
│   └── modals/
│       ├── base-modal.js       # базовое окно
│       ├── medication-modal.js # окно лекарства
│       └── symptom-modal.js    # окно симптома
├── css/
│   └── health-module.css       # Стили модуля
└── pages/
    └── health.html             # HTML страница модуля
```

### Global объект
```javascript
window.HealthModule  // Фасад модуля
window.HealthUI      // UI управление
```

## 🔧 API Endpoints

### GET /health/profile
Профиль здоровья

### GET /health/medications
Список лекарств

### GET /health/entries
Дневник симптомов

### GET /health/logs
Логи здоровья

### POST /health/reminder
Добавление напоминания

Подробнее см. [HEALTH_API.md](../api/HEALTH_API.md)
