# 💰 Модуль "Бюджет и расходы"

Модуль анализа бюджета и управления расходами.

## 📋 Описание

Страница `pages/budget.html` позволяет:
- Отслеживать расходы по категориям
- Анализировать тренды расходов
- Устанавливать бюджеты на категории
- Сравнивать расходы между периодами
- Видеть историю покупок

## ✅ Функциональность

### Статистика
- Общие расходы за период
- Расходы по категориям (диаграммы)
- Самые крупные покупки
- Средние расходы по дням

### Фильтры
- По датам
- По категориям
- По магазинам
- По типу платежа (QR-код, ручной ввод)

### Бюджет
- Установка бюджета на категорию
- Отслеживание потраченного бюджета
- Предупреждение при превышении

### История
- Список всех покупок с фильтрацией
- Детали каждой покупки
- Экспорт (опционально)

## 🔧 API Endpoints

### GET /statistics/budget
Получение статистики бюджета

**Параметры:**
- `period` - день, неделя, месяц, год
- `category` (optional) - фильтр по категории
- `family_id` (optional) - семейные данные

**Ответ:**
```json
{
  "total_spent": 150000.00,
  "by_category": [
    {
      "name": "Молочные продукты",
      "spent": 45000.00,
      "percent": 30,
      "budget": 50000.00
    }
  ],
  "period_start": "2025-01-01",
  "period_end": "2025-01-31"
}
```

### GET /purchases
Список покупок

**Параметры:**
- `limit`, `offset` - пагинация
- `start_date`, `end_date` - диапазон дат
- `category` - фильтр по категории
- `family_id` - семейные данные

## 📊 Структура данных

### Категории расходов
- Молочные продукты
- Хлебобулочные изделия
- Мясо и рыба
- Овощи и фрукты
- Напитки
- Бакалея
- Гигиена и косметика
- Прочее
